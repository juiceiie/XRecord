## 功能特点

### 📁 数据管理
- **分组管理** — 创建、编辑、删除分组，自定义分组颜色
- **卡片条目** — 支持名称、网址、账号、密码、备注
- **本地存储** — 数据存储在本地文件，完全可控
- **文件绑定** — 可绑定任意位置的数据文件

### 🔒 安全隐私
- **AES-256 加密** — 数据文件加密存储，防止内容泄露
- **跨设备同步** — 复制数据文件到其他设备即可使用
- **密码显示/隐藏** — 一键切换，保护隐私
- **快速复制** — 复制按钮一键复制账号密码

### 🎨 界面设计
- **原生体验** — 完美适配 macOS 视觉风格
- **同色点缀** — 卡片自动继承分组颜色
- **拖拽排序** — 自由调整卡片顺序
- **搜索功能** — 快速定位需要的记录
- **首次欢迎页** — 新用户友好的引导界面

### ⚡ 轻量高效
- **Menu Bar 入口** — 菜单栏快速访问
- **秒级启动** — 纯原生实现，无需 Electron
- **离线可用** — 无需网络，本地运行

## 安装使用

### 方法一：下载 Release（推荐）
1. 进入 [Releases](https://github.com/juiceiie/XRecord/releases) 页面
2. 下载最新版本的 `.dmg` 文件
3. 解压后拖入应用程序文件夹

### 方法二：从源码编译
```bash
git clone https://github.com/juiceiie/XRecord.git
cd XRecord

# 首次构建：生成自签名代码签名证书（无需 Apple 开发者账号）
./scripts/create-signing-identity.sh

xcodegen generate
open XRecord.xcodeproj
```
> 没有该证书时，可用 `xcodebuild ... CODE_SIGN_IDENTITY="-"` 退回临时签名（但钥匙串可能随构建失效）。

## 数据加密

数据采用 **AES-256-GCM** 加密：
- 主密钥随机生成并保存在 macOS 钥匙串，日常解锁无需输入密码
- 文件内容不可直接阅读，拷贝单个文件无法解密
- 换设备使用时，先在「设置 → 数据安全」设置**迁移口令**，再把数据文件拷贝过去，输入口令即可解锁

> 迁移口令只用于包装主密钥，不会被保存；遗失后新设备将无法恢复数据，请妥善保管。
